# Handbook Phase Checklist

Current phase per the handbook: Phase 3, AI Council.

## Order To Follow

1. Keep the data pipeline stable.
- Observation, validation, and feature generation must remain the first gate.
- Do not let later-stage work bypass validation or feature creation.

2. Keep AI Council reasoning explainable.
- Every expert must produce an independent recommendation.
- Evidence should remain clear, reproducible, and auditable.
- The council should stay focused on analysis, not broker execution.

3. Hold Phase 3 expansion to handbook order.
- Do not introduce later-phase behavior before the phase boundary is reached.
- Chief Strategist and Risk Engine work should remain aligned with the roadmap.

4. Treat F2 as a Phase 5 activity.
- Wait for the readiness checker to report enough completed `trend_ai_v2` samples.
- Rerun the confidence audit only after readiness is true.
- Compare confidence bins against realized outcomes before changing the formula.

5. Move to Phase 4 only after Phase 3 is stable.
- Phase 4 is Risk Management.
- Risk validation must happen before any execution approval.

6. Use Phase 5 for research and backtesting.
- Build or extend replay, backtesting, and research workflows there.
- Record outcomes, compare strategies, and update knowledge based on evidence.

## Working Rule

Do not skip a phase because a task is convenient.
Each next step must respect the handbook order: validate, analyze, review risk, then execute, then record outcomes, then research.
